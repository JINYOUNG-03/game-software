# 해동국 로우폴리 모듈 리소스

Blender에서 제작한 조선 후기풍 판타지 왕조용 첫 에셋 묶음입니다. 쪽빛·삼베·감물·먹색·탁한 옥색을 사용했습니다. 게임 소스나 프로젝트 설정은 수정하지 않습니다. `tools`의 Python 파일은 Blender 제작·검사용이며 게임 코드가 아닙니다.

## 파일 구성

- `blend/`: 수정 가능한 원본. 인간 8종, 동물 4종, 건축 라이브러리, 자연 라이브러리, 약방 조립 예시.
- `glb/`: 재질·UV·골격·애니메이션을 포함한 glTF 2.0 바이너리. 건축·자연 모듈은 원점 기준 개별 파일.
- `glb/parts/`: 인간과 동물의 슬롯별 메시. 각 파일에 같은 종의 전체 골격과 동작을 포함합니다.
- `textures/`: 256×256 PNG, 7가지 재질의 basecolor와 roughness 14장. 가로·세로 반복 가능. 원본 Blend와 GLB에도 이미지가 포함됩니다.
- `previews/`: Blender에서 렌더링한 확인용 이미지.
- `metadata/asset_manifest.json`: 구성, 폴리곤 수, 골격, 동작 길이, 조립 기준점.
- `metadata/*_parts.json`, `*_slots.json`: 메시별 바인딩 본, 휴지 자세, 슬롯 파일 위치.
- `metadata/animation_graph.json`: 이동·회전·공격·점프 상태 및 블렌딩 제안값.
- `metadata/validation_report.json`: 전달용 GLB의 구조 검사 결과.

## 인간 조립

키 1.75m, 머리 높이 0.25m인 7등신 기본 체형입니다. 상투·신발·짐 등은 이 기준 키 바깥으로 나올 수 있습니다. 인간 프리셋 8종은 동일한 `human_v1` 본 이름·부모·바인드 위치와 11개 동작을 공유합니다. 성인 공통 체형의 초벌 모델이며 성별·체형별 추가 골격은 아직 없습니다.

### 무연항 스토리 프리셋 5종 추가

`HARBOR_PROTOTYPE.md`와 그 문서가 가리키는 원본 `초기_스토리_설정.md`의 주요 인물 5명을 기준으로 추가했습니다. 이름·직업·서사상의 역할은 문서에 근거하고, 얼굴·연령 인상·헤어·복식 등 상세 외형은 이번 미술 제작안입니다. 원문에서 지정되지 않은 성별·나이·직급 복식을 확정 설정으로 추가하지 않습니다.

| 파일 이름 | 인물·직업 | 추가 파츠·형태 |
| --- | --- | --- |
| human_mira_engineer | 미라 벤 · 배수로 기술자 | 뒤쪽 쪽머리, 작업 머릿수건, 양쪽으로 갈라진 긴 앞치마, 천 덧댐, 망치·다림추 |
| human_doyun_clerk | 도윤 렌 · 부두 조합 서기 | 넓은 얼굴, 희끗한 관자 머리·콧수염, 트임 있는 긴 조끼, 장부 가방·붓통·조합 표찰 |
| human_serat_inspector | 세라트 경 · 항만청 조사관 | 각진 턱, 낮은 투구·턱끈, 어깨 덧댐·누비 조끼, 관청 표장, 봉인 문서함·지휘봉 |
| human_ian_broker | 이안 노을 · 야시장 중개인 | 가는 턱, 갓·갓끈, 짧은 턱수염, 앞이 열린 긴 겉옷, 돈주머니·거래 수첩 |

기존 주인공·짐꾼·약방 NPC 파일은 유지했습니다. 추가 프리셋은 새 색상뿐 아니라 머리·얼굴 형태와 의상·장비 메시를 새로 포함합니다. `headwear_` 머리 장비는 `hair` 슬롯, 콧수염·턱수염은 `face` 슬롯에 속합니다. 작업 도구·앞치마는 `accessories`, 긴 겉옷은 `upper_clothing`입니다. 얼굴 폭이 달라진 프리셋은 `head`와 `face`를 같은 프리셋에서 먼저 조합하고, 다른 얼굴 파츠는 위치를 확인한 뒤 사용합니다. 갓과 투구도 다른 머리 폭과 조합할 때 관통 여부를 확인해야 합니다.

새 골격을 추가하지 않았으며 기존 locomotion·회전·공격·점프 조합 명세를 그대로 사용합니다. 망치·끌·지휘봉은 허리 장비 상태이며 손에 들고 사용하는 전용 작업/무기 공격 모션은 없습니다. 긴 옷과 앞치마는 기존 골반·허벅지 본으로 변형하는 기본 의상이며 천 시뮬레이션·별도 옷 본·발 접지 IK는 포함하지 않습니다.

추가분만 재생성하려면 Blender에서 `tools/build_assets.py`에 `-- --story-humans-only`를 전달합니다. 기존 3종과 환경·동물 파일을 다시 만들지 않고 추가 5종과 관련 manifest를 갱신합니다. 같은 이름의 추가분 수동 편집본은 별도로 보관해야 합니다. `previews/story_humans.png`, `previews/all_humans.png`에서 비교할 수 있습니다.

| 슬롯 | 구성 |
| --- | --- |
| body_base | 기본 몸통·목·팔·다리·귀·엄지 |
| head | 얼굴 특징을 제외한 머리 형태 |
| face | 눈·눈썹·코·입 |
| hair | 머리카락·상투·머리띠 |
| upper_clothing | 저고리·소매·깃·고름·띠 |
| lower_clothing | 바지 |
| hands | 손의 본체, 단순화한 벙어리장갑형 |
| shoes | 짚신 |
| accessories | 목도리·지게·보따리·약재 가방·앞치마 등 |

예: 주인공 body_base + 주인공 head/face + 약방 NPC hair + 약방 NPC upper_clothing + 짐꾼 lower_clothing + 공통 hands/shoes. 피부 파츠(head/face/body_base/hands)의 재질은 한 가지 피부색으로 맞춰야 합니다. 손은 엄지와 손바닥이 나뉘지만 손가락 개별 본·표정 블렌드셰이프는 포함하지 않습니다.

Blender에서는 원본 파일에서 필요한 메시를 Append하고 기존 `human_v1` 하나에 Armature Modifier와 부모를 연결합니다. 추가로 가져온 골격을 중복 사용하지 않습니다. 위치·회전·스케일 및 휴지 자세를 바꾸지 말고 본 이름을 유지합니다. 동일 슬롯을 겹쳐 표시하지 않습니다. 기본 몸체는 옷 아래에 남겨 놓았으므로, 엔진에서는 가려진 부분을 숨기거나 제거해 오버드로와 관통을 줄일 수 있습니다.

GLB 파츠에도 완전한 골격이 반복 포함됩니다. 엔진에서는 슬롯별 골격을 별도 애니메이션시키기보다 하나의 공통 포즈를 공유하도록 가져오기 설정을 해야 합니다. 자동 연결을 수행하는 엔진 코드는 이 작업에 포함하지 않습니다.

## 동물

| 동물 | 먹이 | 기본 성향 | 공격 클립 |
| --- | --- | --- | --- |
| 호랑이 | 육식 | 위험 | 물기·앞발 동작 |
| 늑대 | 육식 | 중립/영역 방어 | 물기·앞발 동작 |
| 사슴 | 초식 | 순함/회피 | 비상시 머리받기 |
| 소 | 초식 | 순함/가축 | 비상시 머리받기 |

성향은 게임 로직을 강제하지 않는 메타데이터입니다. 종별 골격에 몸통·머리·앞다리·뒷다리·꼬리·뿔 슬롯을 분리했습니다. 뒷다리는 엉덩이→앞쪽 무릎→뒤쪽 비절→발 순서이며, 고양이·개는 발가락과 발바닥, 사슴·소는 갈라진 발굽을 표현합니다. 사슴의 뿔과 소의 뿔은 제거 가능한 별도 슬롯입니다.

종 내부에서 교체하는 규격입니다. 서로 다른 종의 팔다리를 그대로 끼우면 연결 위치·길이가 맞지 않습니다. 모든 동물의 `run`은 대각선 다리쌍을 쓰는 빠른 트로트 기반 초벌 동작입니다. 호랑이의 전력 질주, 늑대의 갤럽, 사슴의 도약 질주 등 종별 고속 보행은 후속 제작 대상입니다.

## 애니메이션

인간·동물 각각 30fps, 11개 클립을 포함합니다. 원본 Blend의 Action Editor에서 동작을 선택하면 됩니다. NLA 트랙은 원본 동작 보관용으로 음소거되어 있고 기본 Action은 `turn_pose`입니다. GLB는 각 클립을 별개 animation으로 제공합니다.

| 클립 | 프레임 | 용도 |
| --- | --- | --- |
| idle | 60 | 호흡 대기, 반복 |
| turn_pose | 1 | 공통 휴지/회전 보간 기준 자세 |
| walk | 32 | 제자리 걷기, 반복 |
| run | 24 | 제자리 뛰기, 반복 |
| turn_left / turn_right | 각 24 | 90도 제자리 회전 |
| attack | 30 | 인간 맨손 동작, 동물별 공격 |
| jump | 42 | 준비→체공→착지 일체형 |
| jump_start | 10 | 분리형 점프 준비 |
| jump_air | 24 | 분리형 체공, 반복 |
| jump_land | 12 | 분리형 착지 |

걷기·뛰기는 평면 이동 없는 in-place 클립입니다. 원점 본의 수직 바운스와 점프 높이는 들어 있습니다. 엔진 이동량과 애니메이션 재생 속도를 함께 맞추며, 원점 Z를 캐릭터의 물리 점프 높이에 중복해서 더하지 않습니다. 회전은 root에 90도 방향 변화가 들어 있으므로 이동 객체 방향에도 같은 회전을 이중 적용하지 않습니다.

걷기↔뛰기는 정규화된 위상을 유지하며 0.18~0.25초 동안 크로스페이드합니다. 인간은 같은 다리의 스윙 위상을 맞출 수 있습니다. 동물의 walk는 4박자, run은 대각선 트로트라서 전환 때 네 발의 위상을 모두 맞출 수 없으므로 `animation_graph.json`의 별도 규칙을 사용합니다. 전환 속도값과 타격 시점은 엔진 연동 전 조정할 초기 제안값입니다. 모션 캡처나 IK로 발 접지를 보정한 최종 모션이 아닙니다.

`turn_pose`는 정지 또는 방향 전환 때 쓸 기본 A 자세입니다. 방향이 섞인 채로 새 동작을 시작하지 않도록 root 회전 정규화와 자세 블렌드를 함께 처리해야 합니다. 점프는 일체형 `jump` 또는 분리형 3개를 선택하고 동시에 겹쳐 재생하지 않습니다. 분리형 경계는 약 0.08초 블렌드가 필요합니다.

## 건축·생활도구·자연

건축 기준은 2m×2m, 기둥 높이 2.4m입니다. 바닥 중심 또는 기둥 밑이 원점이고 상세 기준점은 manifest에 기록했습니다. 석재 기단 위에 마루, 모서리 기둥, 벽, 보, 지붕, 박공을 조립합니다. 지붕은 처마 여유 0.2m를 포함하며 전후 박공은 별도입니다. 기와 지붕과 초가 지붕을 교체할 수 있습니다. `scene_medicine_shop`은 같은 모듈로 만든 배치 예시입니다.

생활도구는 소반·걸상·옹기·쌀자루·궤짝·약장·등롱·물통·돗자리·장작을 포함합니다. `prop_door_hinged.glb`는 경첩 기준 원점과 `door_open` 스켈레탈 동작을 포함합니다. 환경의 고정 물체에는 불필요한 스켈레톤을 넣지 않았습니다.

`architecture_library.blend`와 `nature_library.blend` 안에서는 모듈을 보기 쉽게 격자로 펼쳐 놓았습니다. Append해서 조립할 때는 메타데이터의 `library_translation_m`만큼 위치를 빼거나, 일반 메시의 Object Location을 0으로 돌립니다. 골격이 있는 문은 자식 메시 대신 골격의 배치 오프셋만 제거합니다. 개별 GLB에는 이 진열용 오프셋이 없으므로 그대로 조립할 수 있습니다.

자연물은 소나무·활엽수·풀·갈대·바위 3종, 흙·풀·돌 지형 타일과 높이차 0.5m 경사 타일입니다. 나무·풀의 바람 애니메이션, LOD, 충돌체와 지형 연결용 코너 메시, 건물 내비게이션 데이터는 포함하지 않습니다. 재질은 목재·흙·돌·삼베·풀·기와·회벽의 색/거칠기 맵이며 별도 노멀 맵은 없습니다. 폴리곤 면으로 형태를 살리는 낮은 광택의 스타일입니다.

## 좌표와 검증 범위

Blender: 미터, +Z 위, -Y 전방. GLB: 미터, +Y 위, +Z 전방. 지면은 원본 Z=0 / GLB Y=0입니다. 같은 규격의 파츠는 변환 적용이나 재중심화 없이 가져옵니다. 애니메이션 root는 발밑 원점입니다.

Blender 배치 제작, 스킨 가중치 합계·본 참조·UV, GLB의 메시·스킨·클립 존재와 파일 구조를 검사합니다. 생성 미리보기와 동작 포즈를 Blender로 렌더링해 확인합니다. 게임 빌드·실행·엔진 내 렌더링은 수행하지 않습니다. 절차적으로 만든 첫 제작본이므로 최종 배포 전에 의상 관통, 발 접지, 경사면 이동, 종별 고속 동작을 엔진에서 추가 조정해야 합니다.

`tools/build_assets.py`를 Blender 백그라운드에서 실행하면 이 묶음의 생성 파일을 다시 만듭니다. 재실행은 같은 이름의 생성 파일을 덮어쓰므로 수동 편집본은 다른 이름으로 보관하세요. 사용자 제작 원본을 자동 탐색하거나 삭제하지 않습니다.
